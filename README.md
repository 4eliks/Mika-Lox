# Mika-Lox Bot 🎤

Telegram бот с смешными рифмами на имена Мика и Микаэл. Присылает новую рифму каждые 15 минут.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

1. Создай бота через [@BotFather](https://t.me/BotFather) и получи токен
2. Установи переменную окружения:

```bash
export TELEGRAM_BOT_TOKEN="твой_токен_здесь"
python bot.py
```

## Команды

- `/start` — запустить рассылку рифм каждые 15 минут
- `/stop` — остановить рассылку
- `/rhyme` — получить рифму прямо сейчас
